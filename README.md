四元数回転のデモプロジェクトです
人工衛星のオブジェクト、カメラを四元数を用いて滑らかに回転させています。
また、初期位置に戻る際には1秒かけて球面線形補間を用いてもとに戻っています

キーボードマウス操作
W/S	    ：赤軸周りオブジェクト回転
A/D     ：緑軸周りオブジェクト回転
Q/E	    ：青軸周りオブジェクト回転

I/K	    ：カメラ上下回転
J/L	    ：カメラ左右回転
U/O	    ：カメラロール回転

ENTER   ：初期位置に戻る
------------------------------------------
ゲームパッド操作(XBoxコントローラー配置)
左スティック	：オブジェクト上下左右回転
LB/RB		    ：オブジェクトロール回転

右スティック	：カメラ左右回転
B/X			    ：カメラロール回転

START       ：初期位置に戻る
